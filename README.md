# Zero · 太阳系轨道

把 Zero 体系里「太阳系轨道怎么形成」这条推导线，做成一个可以**旋转、缩放、平移**的 3D 页面，并附上它依据的五篇原文。

- 页面：`web/index.html`（单文件、离线、内联 three.js，直接双击打开）
- 原文：`articles/`（Zb012 / Zb050 / Zb051 / Zb052 / Zb086）

## 看页面

打开 `web/index.html`。支持 WebGL 的浏览器都可以（Chrome / Edge / Safari 14+ / Firefox 90+）。

| 动作 | 效果 |
|:--|:--|
| 拖动 | 旋转 |
| 滚轮 / 双指捏合 | 缩放 |
| Shift + 拖动 / 右键拖动 / 双指拖动 | 平移 |
| 双击 | 复位视角 |
| ← → | 切换步骤 |

第 3 步「单星（拖拽）」：按住行星拖一条速度矢量，松手发射；开「格距修正」后轨道不再闭合。
太阳系视图默认**随镜头减速**（镜头越近时间越慢，HUD 显示实时倍率），可在控制条关掉。

## 七步

| 步 | 视图 | 内容 | 依据 |
|:--|:--|:--|:--|
| 1 势 | 3D 点云 | `Lφ = −x`；可解 ⟺ 总荷为零；`G ~ 1/(4πσr)` | Zb012 定理 1.2 / 3.1 |
| 2 力 | 3D 箭头 | `F = −q∇φ`；`\|F\|·4πr²` 收敛到 1 | Zb051 定理 1.2 |
| 3 轨道 | 3D 太阳系 / 单星 | 角动量、面积律、Binet、椭圆、`T²∝a³` | Zb051 定理 3.1–5.1 |
| 4 周期 | 2D 图表 | 九颗星共线，偏离 0.5% 来自多体扰动 | Zb051 定理 5.1 |
| 5 半径 | 2D 图表 | `rₙ = r₀·2ⁿ`；点掉木/土/天，F 从 0.2300 升到 0.2723 | Zb050 命题 4.5 / 4.6 |
| 6 地月 | 3D + 曲线 | 潮汐 = 势的 Hessian；`a_f ≈ 1.44a₀`、`T_f ≈ 47.2 d` | Zb052 定理 1.1 / 2.1 / 4.1 |
| 7 账本 | 3D 太阳-质心 | `b_p = a_p m_p/(M+m_p)`；木星单独 742,444 km = 1.067 R⊙ | Zb086 命题 3.1 |

第 4、5 步刻意保留 2D 图表——那两步要读数值，转起来只会更难读。

## 重新构建

```
python3 web/gen_data.py
```

脚本会重算页面用到的每一个数，与原文登记值逐项对照（**15/15 PASS**），再把 `index.src.html` + `three.min.js` + 数据拼成自包含的 `index.html`。页面启动时另有 10 项自检（含 WebGL、开普勒第三定律、地月终态、积分器漂移），结果写在 `#selftest` 元素里。

## 边界

- 页面是可视化，**不是新结论**；结论以 `articles/` 里的原文为准。
- 太阳系视图的 a、e、i 等轨道要素是 JPL 近似值（外部数据）；行星显示大小做了放缩，相位只示意。
- 第 7 步木星距离做了压缩（画面标注），否则 5.2 AU 与 1 R⊙ 无法同框。
- 地月时间轴按距离参数化；退行速率要耗散/滞后模型（原文里的具名条件 C），原文不给时间表。
- 第 3 步「格距修正」按 Zb051 命题 6.1 的 `O(a²/r²)` 形式取示意振幅，不是 `L⁺` 的精确轨道；96³ 力表是真算的。
